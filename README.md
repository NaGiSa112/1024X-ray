# X 光安检图像目标检测

讯飞 AI 开发者大赛 · X 光图像检测赛题的项目实现。

**线上 mAP@0.5 = 77.312**，排名第一（第二名落后 5 分以上）。

---

## 一、赛题背景

机场、车站的 X 光安检机每天产生海量图像，判图员需要在其中找出刀具、压力罐等违禁品。
人工判图效率低、易疲劳，因此需要自动检测算法辅助。

与常规自然图像检测不同，X 光图像有三个特点：

- **物体相互重叠**，成像依赖材质密度而非光照，塑料/液体等低密度物体边缘弱
- **尺度差异极大**，同一个类别可能只占十几个像素，也可能占满画面
- **类间相似**，刀具与剪刀、不同材质的瓶子在灰度图上接近

---

## 二、任务描述

**输入**：一张 X 光安检图像
**输出**：图中所有违禁品的边界框、类别与置信度

共有 8 个类别（提交时按此顺序排列）：

| 序号 | 类别 | 中文 |
| ---: | --- | --- |
| 0 | knife | 刀具 |
| 1 | tool | 工具 |
| 2 | glassbottle | 玻璃瓶 |
| 3 | drinkbottle | 饮料瓶 |
| 4 | metalbottle | 金属瓶 |
| 5 | laptop | 笔记本电脑 |
| 6 | umbrella | 雨伞 |
| 7 | pressuretank | 压力罐 |

**评价指标**：mAP@IoU=0.5，8 个类别**等权平均**（不是按样本量加权，因此小样本类别同样重要）。

## 四、提交格式

一个长度 2,325 的数组，每个元素对应一张测试图（按文件名排序），内含 8 个列表（对应 8 个类别），
每个框为 `[x1, y1, x2, y2, score]`，坐标为原图像素。

```
[
  [[[120.5, 340.2, 200.8, 420.1, 0.87]], [], [], [], [], [], [], []],
  ...
]
```

坐标需满足 `0 < x < 宽` 且 `0 < y < 高`。

## 五、方案简介

```
YOLOv8m + COCO 预训练 @640                              mAP 0.653
      ↓ 换 YOLOv8l + EDS-1 X 光领域预训练
YOLOv8l + EDS-1 @640                                    mAP 0.698
      ↓ 强增强（mosaic / mixup / 上下翻转）
                                                        mAP 0.724
      ↓ 分辨率提到 1024 微调（本题最大单项增益）
                                                        mAP 0.759
      ↓ 测试时增强（TTA）
                                                        mAP 0.783
      ↓ 换 HGNetV2 骨干 + 半监督自训练（两轮伪标签）
                                                        mAP 0.839
      ↓ 七模型 WBF 融合 + 混合分辨率推理
                                                        mAP 0.849 → 线上 77.312
```

**几个关键做法：**

1. **领域预训练**：用同域 X 光数据集预训练的权重初始化，比 COCO 权重高 4.5 分
2. **训练分辨率**：1024 微调带来 +3.5 分；反向操作（640 训练的模型用 1024 推理）反而 −7 分
3. **按 AP50 选权重**：ultralytics 默认按 `0.1×mAP50 + 0.9×mAP50-95` 选最佳权重，与本题指标不一致，改为直接按 AP50 选，+0.83 分
4. **半监督自训练**：把集成模型在测试集上的高置信预测作为伪标签加入训练，让模型直接学习测试集分布
5. **WBF 融合**：**架构多样性比单模型强度更重要**——一个单独只有 0.757 的异构模型贡献 +1.15，而一个单独 0.808 的同源模型贡献 −0.46
6. **混合分辨率推理**：部分成员用 1280 推理、部分用 1024，尺度本身也是多样性来源

## 七、目录与运行

```
├── src/              处理脚本（数据转换、训练、评测、融合、导出、审计）
├── envutils/         环境搭建与实验流水线
├── runs/             各实验的指标、曲线、审计结果
├── submissions/      各阶段提交文件
└── *.md              实验记录与问题报告
```

```powershell
# 数据准备（VOC → YOLO）
python src/prepare_dataset.py

# 训练（按 AP50 选最优权重）
python src/train_map50.py --data data/yolo/data.yaml --name D_ft1024 `
    --weights weights/yolov8_eds1.pt --epochs 80 --imgsz 1024 --batch 6

# 融合评测（支持每个成员独立分辨率）
python src/ensemble_eval.py --models F,B,H1,D,G,S2,S3 `
    --imgsz-map "F=1280,B=1280,S2=1280,S3=1280"

# 导出与校验
python src/export_fused.py --config runs/audit/ensemble/<run>/fusion_config.json
python src/validate_submission.py results_test2_submit_fused.json
```

环境：Python 3.13 / PyTorch 2.11.0+cu128 / ultralytics 8.4.216 / RTX 4090
